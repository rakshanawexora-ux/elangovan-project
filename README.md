# Elangovan Doorstep Services

A responsive Next.js App Router website for Chennai-based independent document assistance. Four routes: Home, About, Services, Contact. Server-rendered content, page metadata, structured business data, service filters, contextual enquiries, keyboard navigation, and reduced-motion support.

## Run in VS Code

Use Node.js 22 or newer.

```sh
npm install
npm run dev
```

Open http://localhost:3000. For repeatable installation use `npm ci`.

## Production

```sh
npm run build
npm start
```

Deploy on a host with Next.js support (for example Vercel or a Node.js server). This project is no longer a Vite/static-SPA app; do not deploy an old `dist/` folder or configure an SPA fallback.

Contact links use +91 7396039571. No secrets or database are required. Generated images are illustrative; the hero is not a portrait of T.R. Elangovan. Visits are by arrangement. When a production domain is chosen, add domain-specific canonical URLs and a sitemap.
